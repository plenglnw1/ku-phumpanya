# 1.4.5 Usability test: Task Completion Rate (TCR)

**Status: script ready. BLOCKED** on three decisions: the tester group, the number of testers, and the dates (meeting decision).

## Goal and criterion

A user can find a cross-disciplinary learning path in **≤ 3 steps**.

- **Gate passes when:**
  - TCR ≥ the agreed target (proposed: 80 %), counting a task as complete when it is done in ≤ 3 steps without help, and
  - no task is abandoned because of a defect.
- **What counts as a step:** one deliberate action that moves toward the goal, such as typing and submitting a query, clicking a tab, a recent search, a chip, or a card. Scrolling and reading do not count.

## Setup

- **Testers:** _[n = ?]_ KU students and staff from the 4 pilot faculties (วนศาสตร์, เกษตร, อุตสาหกรรมเกษตร, ประมง). They should not have used Phumpanya before.
- **Environment:** `https://phumpanya.ku.ac.th`, Chrome on a laptop or a 10" iPad, signed in with the tester's own `@ku.th` account. Consent was given before the session.
- **Facilitator:** reads each task aloud, does not help, and records steps, time, completion, and comments. Screen recording only with the tester's consent.
- **Duration:** about 20 minutes per tester.
