# 1.4.4 Source links return HTTP 200

**Result (2026-10-29): 611 of 612 links return 200 (99.8 %).** The one failure is a page that is broken on the KU Forest site itself.

## Method

```bash
php artisan links:check --corpus=../KU-BCG/elastic-search/data/all_docs.json --concurrency=3 --delay=500
```

- **What is checked:** every `url` in the indexed corpus, which is the same export loaded into Elasticsearch on KU. The run also includes the seed-config links (`config/graphrag_seed.php`) and the evidence URLs of stored search results, but seed URLs that already appear in the corpus are counted once.
- **How:** a `GET` per URL with a 20 s timeout, 3 in parallel, and 500 ms between batches. A link passes only on HTTP 200.
- **Where it ran:** a workstation on the KU network. Running it on the KU host is not allowed: on 2026-10-29 a run there pushed load to 81 and the kernel OOM-killed Elasticsearch and Neo4j.
- **Raw report:** [`1.4.4-links-20261029.json`](1.4.4-links-20261029.json).
